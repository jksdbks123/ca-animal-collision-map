# California Animal Collision Risk

Static site: which stretches of California's state highways have the most police-reported crashes with animals
per mile driven (2016–2025, adjusted for traffic). Live at https://jksdbks123.github.io/ca-animal-collision-map/

Data: California Highway Patrol CCRS (public domain); Caltrans Traffic Census and GIS (CC BY; Caltrans does not
warrant the accuracy of these estimates and does not endorse this site). Basemaps © OpenStreetMap contributors via
OpenFreeMap; imagery USGS The National Map. Built files only; not an official product of any agency.
